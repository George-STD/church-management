# ⛪ منظومة إدارة الخدمة الكنسية (Church Service Management System)

> **الإصدار:** 1.0 (Enterprise Grade)  
> **الهندسة:** Clean Architecture / Domain-Driven Design (DDD)  
> **قاعدة البيانات:** **Supabase (PostgreSQL)** عبر Prisma ORM  
> **الواجهة:** React 19 + TypeScript + Vite + Tailwind CSS (Native RTL Arabic Mobile-First)  

---

## 🌟 أبرز ميزات المنظومة

1. **الهيكل الهرمي التراكمي الصارم (Cumulative RBAC + ABAC):**
   - 5 مستويات صلاحيات هرمية دقيقة:
     1. **خادم (Servant):** حضور فصله، تقديم التحضير، خزنته الروحية الخاصة، تعديل تقييم مخدوميه المسندين فقط.
     2. **مساعد أمين الخدمة (Assistant Secretary):** إدارة كشوف المخدومين بالمرحلة ومتابعة الحضور.
     3. **أمين الخدمة (Stage Secretary):** اعتماد التحضيرات، تقييم الخدام، نشر الإعلانات، إدارة تدبير السنة وتصدير التقارير.
     4. **أمين قطاع (Sector Secretary):** إشراف شامل على مراحل القطاع وتقييم أمناء المراحل.
     5. **أمين عام (General Secretary):** صلاحية كنسية شاملة، نقل الخدام وتجميد الحسابات.

2. **قواعد الخصوصية وسرية القُصّر (Minors Data & Zero-Leak Spiritual Vault):**
   - عزل تام لسجلات الحياة الروحية (الاعتراف، التناول، الصلاة) في خزنة مشفرة لا تظهر لأي مسؤول.
   - قيود صارمة على وصول الخدام لبيانات المخدومين غير المسندين إليهم.
   - تسجيل فوري لكل عملية تعديل أو تصدير في سجل الرقابة والأمان (`AuditLog`).

3. **تسجيل الحضور السريع والافتقاد التلقائي (Attendance & Absence Engine):**
   - واجهة سريعة باللمس (Rapid Tap) لتسجيل حضور القداس والخدمة في ثوانٍ أثناء خدمة مدارس الأحد.
   - محرك رصد الغياب المتكرر يطلق تنبيهاً فورياً عند غياب المخدوم أو الخادم لأسبوعين متتاليين للتواصل والافتقاد.

4. **تصدير تقارير Excel عربية منسقة (RTL Excel Exporter):**
   - توليد ملفات Excel من اليمين إلى اليسار بأسلوب فاخر وتنسيق دقيق للكشوف والإحصائيات.

## 🚀 البدء السريع (Quick Start)

### 1. المتطلبات
- Node.js v20+ أو v24
- حساب مجاني على [Supabase](https://supabase.com)

### 2. إعداد قاعدة بيانات Supabase
راجع الدليل المفصل بالعربية: [SUPABASE_SETUP.md](file:///e:/Coding/Vibe%20Projects/Church/SUPABASE_SETUP.md).

ضع بيانات الاتصال في `server/.env`:
```env
DATABASE_URL="postgresql://postgres.[PROJECT-REF]:[PASSWORD]@aws-0-[REGION].pooler.supabase.com:6543/postgres?pgbouncer=true"
DIRECT_URL="postgresql://postgres:[PASSWORD]@db.[PROJECT-REF].supabase.co:5432/postgres"
```

ثم نفّذ:
```bash
npm run prisma:generate
npm run prisma:push
npm run prisma:seed
```

### 3. تشغيل النظام محلياً
```bash
# تشغيل الخادم والواجهة معاً:
npm run dev

# الواجهة تعمل على: http://localhost:5173
# الخادم يعمل على:  http://localhost:5000
```
